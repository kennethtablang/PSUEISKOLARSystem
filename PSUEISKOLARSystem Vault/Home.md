## ⭐ Key facts at a glance
- **Stack:** ASP.NET Core (`net10.0`) API serving a **React (Vite)** SPA · **SQL Server** + EF Core · JWT · SignalR · MailKit. See [[Tech Stack]].
- **Roles:** [[User Roles & Permissions|Administrator, Scholarship Coordinator, Scholar]].
- **Single campus:** the system now targets **PSU Lingayen Campus** only (multi-campus support is being removed — see [[Roadmap & Status]]).
- **Design language:** Neomorphism (cards/inputs) + Claymorphism (buttons); PSU Blue `#003087` / Gold `#f5b800`; light/dark/system theming. See [[Frontend Architecture]].
